# Deno 來源與授權候選集合

本目錄新增的 deno-cargo-superset/、deno-upstream/、deno-v8-source/ 與 deno-v8-submodules/ 保留上游原文。這是保守收集的來源候選全集，含開發、測試、建置與其他平台元件，不表示每個元件都進入 Windows 執行檔。

版本、來源 URL、checksum 與取得紀錄見 ../deno-registry-sources.json、../deno-upstream-licenses.json、../deno-v8/。尚有未取得聲明與原生嵌套相依，不能宣稱此集合完整涵蓋 Deno 二進位。必須在正式發行前完成目標相依核對。
