# Windows 桌面版與 YouTube 匯入設計

狀態：使用者已於 2026-10-15 確認「照這份做」；進入實作計畫階段。

## 目標與已確認需求

使用者希望將專案放上 GitHub，讓有需要的人自行下載使用；已確認先以 Windows 安裝版為目標。一般使用者不需要開發環境、不需要手動執行下載工具。保留現有音檔搭配 TXT/LRC 匯入、難度選擇、播放、填空與本機進度。

本提案的預設範圍：Windows 10/11 x64、單首公開 YouTube 影片、英文字幕、所有處理與保存都在使用者電腦。下載成功後可以離線練習。網站版保留原有檔案匯入，不會獲得執行本機程式的能力。

## 方案比較與建議

| 方案 | 適用性與取捨 |
| --- | --- |
| Electron 桌面包裝（建議） | 沿用 Expo Web / React 畫面，由獨立主程序執行下載；開發整合直接，但安裝檔較大。 |
| Tauri 桌面包裝 | 可沿用網頁畫面，需要新增 Rust 與 WebView2 開發、打包流程，這個專案的維護技術種類增加。 |
| 網頁搭配獨立輔助程式 | 重用目前預覽方式，但使用者要管理兩個程式及連線狀態，不符合簡化安裝的主要目標。 |

採 Electron 與 electron-builder 的每位使用者 NSIS 安裝程式。現有 Expo 原始碼維持為介面來源，桌面載入打包後的靜態資源，不依賴開發伺服器。

## 使用流程

1. 從 GitHub Releases 下載 Windows 安裝檔並安裝。
2. 開啟程式，在匯入頁選「YouTube 網址」或現有「本機檔案」。
3. 貼網址後檢查單首影片：顯示名稱、長度、可用英文字幕及字幕是否為自動產生。
4. 開始下載：顯示檢查、下載、轉換、整理字幕等階段，可取消。一次處理一首。
5. 音訊及歌詞就緒後沿用題數預覽與三種難度；使用者按儲存後才加入曲庫。

優先選人工英文字幕，沒有時使用英文自動字幕並標示需校對。沒有英文字幕時保留已取得的音訊供使用者選取 TXT/LRC 補上；不會把缺少歌詞的歌曲儲存成可練習項目。若影片不可下載或工具失敗，顯示可理解的原因與重試入口，檔案匯入仍可用。

第一版不處理播放清單、直播、登入 Cookie、會員或付費內容；不加入 AI 語音辨識。網址只接受 YouTube 的單首影片格式，移除無關查詢參數後交給下載程序。

## 程式邊界

- `desktop/`：Electron 主程序、預載橋接、下載工作管理與桌面檔案保存。
- 現有 `src/`：保留練習介面與純函式解析／挖空規則；新增桌面能力介面和 YouTube 匯入元件。
- 桌面橋接只提供具名的檢查、下載、取消、保存及讀取能力；不提供任意命令、任意路徑或通用 IPC 呼叫。
- 主程序重新驗證參數、呼叫來源與工作擁有者，使用不經 shell 的參數陣列啟動子程序。啟用 context isolation、renderer sandbox，停用 Node integration，阻擋非預期導覽與新視窗。
- 靜態 App 與桌面音訊透過限定路徑的本機自訂協定供應，支援音訊 range request；不開放公網 HTTP 服務。外部網址不載入具備桌面橋接的視窗。

## 音訊、歌詞與持久保存

桌面音檔保存於 App 的 userData 目錄，透過工作 ID／歌曲 ID 取得，前端不得指定任意檔案位置。每次下載使用獨立暫存目錄；取消、失敗、關閉程式與下次啟動會清理未完成工作，不把測試或半完成項目加入曲庫。

下載完成後取得 MP3，字幕轉成標準化 LRC。處理自動字幕的累積重複片段、標記、時間排序及沒有可練習英文的內容，之後沿用 `parseLyrics` 和 `prepareExercise`。既有上限沿用：音訊 50 MB，歌詞 300,000 字元及 1,500 行；單片最長 20 分鐘，工作最長 10 分鐘。輸出實際大小再次檢查，不只依賴影片 metadata。

曲庫與音檔使用先準備、再提交的保存流程；失敗需回復，單首檔案遺失不能阻擋其他歌曲。重啟桌面版後可繼續使用曲庫及難度分離的答案草稿。桌面使用固定 origin 與專用使用者資料目錄；目前瀏覽器 localhost 資料不會自動移轉，也不會清除。

## 工具與版本

打包包含 Windows x64 的 yt-dlp、FFmpeg、ffprobe，以及 yt-dlp 所需的 JavaScript runtime（預設 Deno）。官方 yt-dlp executable 的 EJS 支援需在實作時對所選版本實測。使用建置階段取得的固定版本與校驗碼，不讓一般使用者自行配置 PATH，也不在執行下載時任意取得遠端程式碼。

工具版本、來源 URL、SHA-256 和授權資訊由版本清單管理；版本值在實作時依官方 release 選定與驗證。保留第三方授權及對應原始碼／建置來源材料，發布檢查確認滿足所選 binary 的再散布要求，不能只附專案 MIT 檔案就宣稱涵蓋所有工具。

第一版透過更新整個 App 取得工具更新，不做獨立熱更新或背景自動更新。下載工具版本過舊、YouTube 限流或服務改版可能造成失敗，介面提示更新 App 或改用本機檔案。

## 驗收與測試

1. 既有測試、型別與 lint 保持通過；桌面主程序加入網址、參數、字幕正規化、輸出檔案限制、取消／逾時與資料回復測試。
2. 可建立 Windows x64 安裝檔，在沒有全域 Python、yt-dlp、FFmpeg 的環境啟動；內建歌曲與本機檔案匯入可離線使用。
3. 測試人工字幕、自動字幕、缺字幕、無效網址、下載失敗、取消及再次重試；真實下載只使用可取得且有權下載的測試內容，網路失敗與程式測試分開記錄。
4. 下載後可預覽題數、選三種難度、播放與計分；重啟後音檔及進度仍存在。
5. 所有 UI 測試使用獨立 Electron 測試資料目錄，結束後清理，不能再把測試歌曲留在使用者曲庫。

驗收紀錄區分：原始碼測試、打包成功、實際安裝啟動、真實 YouTube 下載；沒有執行的檢查不得當作通過。
