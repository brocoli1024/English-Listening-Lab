範圍：GitHub 提供 Windows x64 安裝版。這次為程式碼、設定、既有驗收紀錄與上游文件盤點；沒有重新執行測試，也不是完整安全或法律審查。沒有修改產品或發布任何檔案。

## 結論

本機試用版已可用；尚未達到正式公開發行條件。優先補齊發行材料與資料管理，再用乾淨電腦驗收。不要用單一完成百分比掩蓋未完成的發行門檻。

2026-10-15 驗收紀錄列出 37 項 Jest、17 項桌面測試通過，並完成實際下載轉 MP3、安裝、同版本重裝與資料保留測試。2026-10-16 使用者確認相容版 LRC 可匯入。這不代表原始 LRC 相容性缺陷已修復，也不代表不同版本升級已驗證。

## 發布前必須處理

1. 第三方發行材料與儲存庫內容
   - THIRD_PARTY_NOTICES.md 明確記錄 FFmpeg 相依來源／重建與重新連結材料、yt-dlp 執行檔相依來源與聲明尚不完整。應依實際打包版本與授權逐項核對；獨立執行 FFmpeg 不等於 App 直接連結其函式庫，不應直接套用所有連結情境要求。
   - LICENSE 目前只列 Expo/650 Industries 的 MIT 聲明。需保留上游權利聲明，釐清並補上本專案原創部分的權利人與授權。
   - artifacts/ 中有使用者提供的商業歌曲歌詞副本，git status 顯示未追蹤，而 .gitignore 未排除；發布前應排除私人匯入材料，逐項審查待提交清單。這些檔案目前未被提交，不應誤稱已公開。
   - 建立元件、版本、授權、來源、對應附件清單，以及發布附件核對流程。

2. 修正已確認的匯入缺陷
   - src/utils/importLyrics.ts 不接受 [id:...]，offset 不接受冒號後空格；原始檔仍會失敗／忽略偏移。
   - 有時間標記的標題被當成歌詞；建議匯入預覽提供「排除此行」，避免用粗略自動判斷誤刪真正歌詞。
   - 驗收：原始問題檔可讀取，偏移生效，能排除標題；錯誤訊息指出行號／原因；以自製文字建立回歸測試，不將商業歌詞加入公開測試。

3. 使用者可自行維護資料
   - importedSongs.ts 目前提供讀取與新增，沒有完整的使用者刪歌流程；底層 removeAudio 主要用於新增失敗回復，不能當成已有刪歌功能。
   - 至少提供刪除匯入歌曲及確認操作，處理相關音檔、草稿、成績；匯錯內容能自行重新匯入。
   - 正式版應有可操作的備份／還原方式與損壞資料處理；完整的一鍵匯出介面可延後，但需先驗證文件中的備份方式與還原結果。

4. 可重現的發布流程
   - 沒有 Git remote；大量本次與既有變更尚未提交。應逐項整理保留，不可直接全部加入版本控制。
   - GitHub Actions 已有建置流程，但公開庫不輸出 artifact，沒有 Release 發布步驟；尚無雲端成功執行證據。
   - 需要從乾淨 checkout 完整建置成功、確定支援的 Windows 版本、版本號／變更紀錄、安裝檔＋校驗碼＋完整來源附件，及可追溯的 tag/commit。
   - 目前沒有自動更新；首版可採手動安裝更新，但應提供版本查看、更新連結與失敗回復說明。

5. 真實環境驗收與使用說明
   - 至少在沒有 Node/Python/FFmpeg 開發環境的乾淨 Windows x64 電腦驗證；另測不同版本升級、資料保留／還原。
   - 實際有英文字幕的影片尚未驗收；補測手動字幕、自動字幕、缺字幕、網路中斷／取消、影片不可用等主要路徑。
   - 正式版前核對目前依賴警告，區分開發工具與真正打包／執行路徑，記錄處理結果；本次未跑完整安全掃描，不能宣稱沒有漏洞。
   - README 說明本機檔案不會上傳，但應更清楚區分本機匯入與 YouTube 連線，寫出儲存位置、刪除／卸載行為、支援格式、回報問題方式與使用者內容權利要求。

## 可延後／不一定阻擋公開測試版

- 程式簽章：目前明確未簽章。建議一般使用者正式版採用；未簽章不是技術上不能發布，但會增加來源信任與安裝提示問題，不應要求使用者關閉防護。簽章不保證所有信譽提示立即消失。
