# VMware Windows 最終驗收

狀態：待在乾淨虛擬機執行，不能以開發主機結果勾選通過。

## 準備

使用乾淨 Windows 10/11 x64 虛擬機，建立未安裝本 App 的快照。不要預裝 Node.js、Python、FFmpeg、yt-dlp 或 Deno。記錄 Windows 版本、VMware 版本及測試日期。測試資料使用自有或可使用的音訊／歌詞，勿使用唯一私人副本。

從本機 release 複製兩個安裝檔及其 .sha256：1.0.0（10/20 更新候選）與 1.0.1。1.0.1 的 SHA-256 為 `ebcacc26e66c6403b21cdeb9c3f9a97c17ac737f6c0c94f2fd354f9e5f580e3b`。以 PowerShell `Get-FileHash` 核對 SHA-256，記錄實際值，避免把另一份同版本安裝檔混用。

## 五組驗收

1. **乾淨安裝與啟動**：安裝 1.0.0，啟動、播放內建歌曲、作答並查看成績；確認不要求外部開發工具。關閉後再次啟動。記錄是否出現 Electron 啟動錯誤。
2. **建立可比對資料**：匯入一首音訊及 TXT/LRC，保留未完成答案草稿，再完成另一筆練習成績；記錄歌名、草稿與成績截圖。完全關閉 App，複製整個 %APPDATA%\English Listening Lab 到獨立備份位置。
3. **跨版本安裝升級**：執行 1.0.1 安裝程式覆蓋升級。從捷徑啟動，在「說明與支援」確認版本 1.0.1；驗證歌曲可播放、草稿及成績保留。不能只以解包直接執行代替這一步。
4. **完整還原**：關閉 App，將目前資料目錄改名保留，再將步驟 2 的完整備份放回。啟動 1.0.1，驗證音訊、曲庫、草稿與成績。保留原始備份直到驗收結束。
5. **支援與下載**：在支援頁確認版本、授權全文、第三方通知及還原說明可讀；用公開可用影片測試英文字幕匯入與保存重啟。測試取消、無字幕時改用 TXT/LRC。移除程式後確認資料保留，再重裝確認可讀取。

## 回報欄位

每組填 PASS／FAIL／NOT RUN，不得留空當作通過。附 Windows 版本、兩份 installer SHA-256、失敗步驟、錯誤文字及必要截圖（遮住私人資料）。若出現 0x80000003，保留 Windows 事件檢視器的應用程式錯誤及故障模組，不要直接認定是 App 程式錯誤或主機問題。

本輪本機的啟動、備份還原及解包資料相容性檢查只能作為輔助證據。正式驗收必須補上此表的虛擬機結果。
